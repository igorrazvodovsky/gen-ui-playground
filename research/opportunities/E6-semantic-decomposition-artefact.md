# E6 — Semantic decomposition as editable artefact

For a generated UI, produce the semantic decomposition (Product → Design System → Feature → Component) as a visible, editable artefact. Measure: does exposing this layer improve users' ability to steer the output?

## What it validates

Park et al. show p<.001 for perceived control. This experiment adapts their finding from design-tool context to generative UI.

## Measure

- Can users identify what drove a given component choice?
- Does editing the decomposition produce expected changes in the rendered output?
