The frontend declares which operations the agent can perform. The user can grant or revoke capabilities dynamically. Agent proposes; user (or application policy) disposes.

## Riskiest assumption

Tool granularity can be set at a level that's both safe and useful — not so coarse that the agent is useless, not so fine that approval fatigue kills the interaction.
