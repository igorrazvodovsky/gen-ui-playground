One primary agent decomposes the task and delegates sub-tasks to specialist agents via A2A. The orchestrator maintains global state and resolves conflicts. Simple but creates a single point of failure.

## Riskiest assumption

Sub-task boundaries can be cleanly defined. Real tasks have cross-cutting concerns that don't decompose neatly.
